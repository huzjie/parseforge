# 版面分析提示词

## 适用场景
输入一页文档（图片/PDF），输出带语义类型的版面区域。

## 提示词模板
```
你是文档版面分析器。请把这张文档页切分为若干区域，为每个区域标注类型与边界框。

允许的类型（严格限定）：
- title（标题）
- text（正文段落）
- table（表格）
- chart（图表）
- formula（公式）
- figure（插图）

输出必须是 JSON 数组，每个元素形如：
{"type": "table", "bbox": [x0, y0, x1, y1]}

要求：
1. 不要遗漏任何可见区域；
2. 不要输出 JSON 之外的任何解释文字；
3. bbox 使用整数像素坐标。
```

## 工程要点
- **类型词汇表与下游一致**：类型集合必须和表格/图表/公式三个专用解码头对齐，
  否则后处理要写一堆 if/else 兜底。
- **先分区域再识别内容**：把「版面切分」和「内容识别」解耦，比一次性端到端更稳、
  也更容易单独评测（对应 OmniDocBench 的 region 分项）。
