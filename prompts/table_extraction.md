# 表格提取提示词

## 适用场景
给定一个表格区域，输出结构化单元格（含表头、合并单元格）。

## 提示词模板
```
把这个表格转成结构化 JSON：
{"has_header": true, "rows": [["h1", "h2"], ["a", "b"]]}

要求：
1. 第一行若为表头，has_header 设为 true；
2. 合并单元格在第一个单元格填值，其余填 null；
3. 数字保持原值，不要加单位；
4. 只输出 JSON。
```

## 工程要点
- **合并单元格用 null 占位**：这是最容易踩的坑——直接把合并格子的值复制到所有
  被合并位置会导致下游统计翻倍。约定「首格填值、其余 null」，配合 span 检测还原。
- **数字归一化**：千分位、百分号、货币符号统一在解码后处理，别让模型猜。
