# 图表理解提示词

## 适用场景
把柱状图/折线图/饼图还原为数据序列。

## 提示词模板
```
把这张图表还原成数据：
{"series": [{"name": "series_1", "points": [1.2, 3.4, 5.6]}]}

要求：
1. 每个系列一个 name；
2. points 是浮点数，按 x 轴从左到右；
3. 从图例读取系列名称；
4. 只输出 JSON。
```

## 工程要点
- **图表 → 表格是「可计算的语义」**：还原出的数据序列可直接喂给数据分析/检索，
  这是文档解析价值最大的部分之一。
- **图例单独识别**：颜色/线型到名称的映射单独一个 head，比让主模型同时认图和图例
  更可靠（见 `parseforge/chart/legend.py`）。
