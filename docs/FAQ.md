# FAQ

**Q: 为什么零依赖？**
A: 目标是「读代码学习 + 秒级跑通」，不因装 numpy/pytorch 卡住。

**Q: skill 到底是什么？**
A: 一个能力标量，控制 mock 后端能否正确识别区域类型/单元格/数据序列。0.5=随机，1.0=全对。

**Q: region_accuracy 为什么从 ~0.5 起步？**
A: skill=0.5 时 boost=0，后端纯随机猜 6 种类型之一，正确率就是 ~1/6≈0.17 的数学
期望之上的「随机命中 0.5」（命中判定 P=0.5，命中则取真值、未命中才随机错）。

**Q: 能接真实模型权重吗？**
A: 解析编排逻辑（版面 + 表格 + 图表 + 约束解码）与具体权重无关。把 `_build_result`
换成真实模型输出即可复用同一套 `OmniParser` + 评测框架。

**Q: 表格合并单元格为什么填 null？**
A: 把值复制到所有被合并位置会导致下游统计翻倍。约定「首格填值、其余 null」，配合
`table/span.py` 的 span 检测还原。
